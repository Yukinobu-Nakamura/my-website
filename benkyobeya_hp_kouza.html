この講座で学べること

「ホームページを作りたい(作ってもらいたい)けれど、何が必要で、何にお金がかかるのか分からない」——この講座は、そんな方のためのものです。

実は、ホームページに必要なものは11個ほどしかありません。しかもすべて「家を建てる」に例えられます。この例えを一度頭に入れると、業者さんの見積もりも、レンタルサーバーの広告も、ぐっと読めるようになります。

1. 自分で作る? 外注する? —— メリット・デメリット

最初に、自分で作る場合の損得を整理しておきます。

自分で作るメリット

  1. コンテンツを、後からいかようにも追加できる。外注では「ページを1枚足したい」だけで見積もり・発注・納品待ちの往復になりますが、自作なら思い立ったときに足せます(実際、この「勉強部屋」も思い立った翌日に公開されました)。更新の速さは費用以上の価値があります。
  2. 費用が安い。毎年かかる固定費はドメインとサーバーで年1万円前後。AIの利用料を足しても月数千円です。
  3. 今の時代、AI活用でなんとかなる。コードが読めなくても、日本語の指示だけでAIが「建物」を建ててくれます。このサイト自体がその実例です。

デメリット(正直に)

  1. 自分の時間を使う(このサイトの場合、夜間作業中心で実働約2週間)。時間をお金で買いたい人には外注が合理的です。
  2. 責任は全部自分。掲載内容の正しさ・法律まわり・動作確認は誰も代わってくれません(第4章「施主の責任」参照)。
  3. トラブル対応も自分。ただしそれもAIと一緒なら乗り切れます(第3章のQ&A「スパム」参照)。

3. よくある疑問 Q&A

ドメインは無料でも取れるって聞いたけど?

取れます。ただし無料には2種類あります。①「間借り」型(サービス名が入ったサブドメイン。住所でいうと「〇〇ビル内 △△様方」で、サービス側の都合に左右される)、②「セット込み」型(サーバー契約とセットで実質サーバー代に込み)。途中で独自ドメインに引っ越すと、検索での評価も、QRコード入りの印刷物も作り直しになります。長く使うサイトなら、最初から自分名義の独自ドメインが結果的に一番安くつきます。

ドメインで一番気をつけることは?

名義です。制作を外注する場合でも、ドメインは必ず自分(自団体)名義で取得すること。業者名義で取られると「住所が他人の名義」になり、業者を変えるときにサイトごと動かせなくなります。

高性能なサーバーが必要と言われたら?

文章と写真が中心のサイトは、月数百円のレンタルサーバーで十分です。アクセスが集中してもまず落ちません。動画をサイト上で直接配信するなど特殊な用途がない限り、高性能プランは不要です。

FTPとかPHPとか、覚えないとダメ?

名前は覚えなくて大丈夫です。FTPは「ファイルをサーバーに運ぶときの共通ルール」(郵便制度のようなもの)で、実際の操作は無料ソフトのドラッグ&ドロップです。PHPは「サーバー側で動く裏方のプログラム」で、フォームから届いた内容をメールで送る、といった仕事をします。見た目のファイル(HTML等)は閲覧者の手元で動き、裏方(PHP)はサーバーの中で動く——この役割分担だけ知っていれば十分です。

今はAIでホームページが作れるって本当?

本当です。「建物本体」にあたるHTML/CSS/JavaScriptは、AIに日本語で指示すれば書けるようになりました。「トップに写真を置いて名前を大きく」「スマホで写真が見切れるので直して」——この程度の指示で形になります。このサイト自体も、その方法で作られています。

フォームを置いたら、スパムが来るって本当?

来ます。公開されたフォームを自動巡回して、デタラメな文字列を投げ込むプログラム(ボット)が世界中で動いています(このサイトも公開2週間で見つかり、数十件届きました)。厄介なのは、フォームに「受付完了」の自動返信を付けている場合——スパムの差出人アドレスに自動返信を撃ち返してしまい、ドメインの信用を下げるおそれがあります。対策は無料でできます: ①人間には見えない罠の入力欄(honeypot)を仕込み、埋めてきたらボットと判定して破棄 ②日本語が1文字もない送信は受け付けない ③スパムと判定した送信には自動返信を送らない。この3点で、翌日からスパムはゼロになりました。「郵便受けには防犯」——公開したら終わり、ではないのです。

4. AIで作るときの心得 —— AIは大工、自分は施主

ただし「全部お任せ」ではありません。施主は設計図が読めなくてもいい代わりに、完成した家に自分で住んでみて確かめる責任があります。具体的には3つです。

  1. 中身の正しさは自分の目で確認する。コードの間違いは表示が崩れるのですぐ気づけますが、文章や数字の間違いは正常に表示されてしまうため発見が遅れます。経歴・実績・連絡先は必ず自分で読む。
  2. 法律・ルールに関わる記載は一次情報で裏を取る。個人情報の扱い、業種ごとの表示義務などは、AIの出力を鵜呑みにせず公的機関の資料で確認する。
  3. 検証は「使ってみる」でできる。スマホで全ページを開く、フォームから自分でテスト送信してみる、自分の名前で検索してみる。コードが読めなくてもできる品質チェックです。

5. 用語ミニ辞典

ドメイン
ネット上の住所(例: nakamura-yukinobu.jp)。年単位で借りる。名義は必ず自分に。
サーバー
ホームページのファイルを24時間置いておくコンピューター。土地にあたる。月数百円から借りられる。
HTML / CSS / JavaScript
ページの骨組みと文章 / 内装デザイン / 動く仕掛け。3点セットで「建物本体」。
FTP
File Transfer Protocol。ファイルをサーバーへ運ぶための共通ルール。専用の無料ソフトで操作する。
PHP
サーバーの中で動くプログラミング言語。フォームのメール送信などの「裏方」を担当。
SSL / https
通信を暗号化する仕組み。アドレスバーの鍵マーク。今は無料で設定でき、事実上の必須。
SEO
検索エンジン最適化。まずは「Googleにサイトの存在を届け出る」ことから始まる。

おわりに

まとめると——ホームページの固定費は年1万円前後。残りは「建てる人件費」で、その多くは今、AIで置き換えられる。自作最大の果実は「思い立ったら翌日に足せる」機動力。ただし中身の確認・法律・使って検証は人間の仕事で、公開後は郵便受けの防犯(スパム対策)も忘れずに。この構造を知っていれば、自作するにも、外注するにも、納得して判断できるはずです。
